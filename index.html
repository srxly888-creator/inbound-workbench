阶段 1 · 广告询接 → 接住流量

  • 官网每个咨询/签证按钮都跳 WhatsApp，客资几乎全从 WA 来。
  • 确认成交号跑在 WhatsApp Business 上（普通号狂发模板会被风控限流）。
  • 用「标签」区分阶段，用「快捷回复」存高频话术。
📌 红线：个人号跑业务且狂发模板 → 触发风控，号没了客资全丢。参考 模块00 卖点 + 模块03 话术。

阶段 2 · 有效询盘 → 首响≤2小时

  • 破冰：模板化但个性化，带称呼、带 emoji、三问抛出去。
  • 需求五问：人数 / 日期或月份 / 天数 / 目的地 / 预算或风格。
  • 有效询盘即问邮箱/微信备用联系方式（WA 消息易丢，高客单必须留邮箱发报价 PDF）。
  • 当天在 模块02 客资跟踪 建档。
📌 卡欧美时差：用 World Time Buddy 看客户当地上午发。

阶段 3 · 签证/异议 → 第一道门槛

  • 客户第一句往往是「我能不能进？怎么进？」——签证是入境客第一门槛。
  • 用 模块04 签证查询工具 30 秒判断：免签 / 240h 过境 / 需 L 签，按国籍分支话术。
  • 信任三钩子：可退款 / 无购物 / 英文向导 + 24/7，主动打消安全顾虑。
  • 不承诺签证结果，只说「可协助 + 提供邀请函」。
📌 红线：一套话术通发不同国籍 → 对 A 国正确、对 B 国违规。必须按国籍分支（见 模块03 张家界分国家准备）。

阶段 4 · 报价方案 → 匹配产品

  • 从 模块01 产品矩阵 先甩 1–2 条现成线路「钩住」，再说明可定制；附官网链接 + 景点图。
  • 报价单含/不含写清楚（USD 标价），顺带提示定金与退款政策。
  • 用 模块03 的 /quote 快捷回复发标准报价说明。
📌 价格锚点：首次接触给「2人X天约 $XXX 起」能过滤羊毛党。

阶段 5 · 跟进逼单 → 临门一脚

  • 逼单：档期紧张 / 限时优惠，引导付 30% 定金锁档期。
  • 按 A/B/C 客户类型设计 3 套跟进（C 类长线客户做多城联动交叉销售）。
  • 每次跟进在 模块02 客资表 更新阶段/记录，别漏记。
📌 标★口径（收款/退款/签证协助）先问主管确认再对外发。

阶段 6 · 成交交付

  • 收定金 → 建群 / 拉导游 → 行前 48h 提醒。
  • 境内联络方案写进行前模板：中国境内 WhatsApp 受限，引导装微信 + 买 eSIM，行中切微信。
  • 行前素材从 模块07 素材库 取景点图/好评截图。
📌 最易翻车点：客户一落地就联系不上你。行前必须讲清境内联络方案。

04优化看板 · 哪里还能更好（来自模块03话术评估）

《张家界进线话术评估》列了 11 个缺口，主要落在模块03（话术）。勾选代表已补/已做，状态存浏览器，下次还在。

红线签证/入境前置
话术完全没碰签证，而签证是入境客第一门槛。加 240h 过境+L签+邀请函标准块，按国籍分支（模块04）。
红线开场信任钩子
缺品牌/可退款/无购物/24-7/英文向导。欧美客最怕购物团/被骗，开场必须给 reassurance（模块00）。
红线境内联络方案
中国境内 WA 默认不可访问，客户落地即失联。行前必须讲清：装微信+eSIM/VPN，行中切微信（模块07）。
红线备用联系方式
有效询盘即问邮箱/微信，用于发报价 PDF，否则报价发 WA 被刷走白谈（模块02）。
重要公司署名
中文法律主体英文直译对外国人是噪音/减分，统一用品牌名+官网，法律主体仅对公出现。
重要价格锚点
首次接触给「2人X天约 $XXX 起」软锚，过滤低意向、加速决策（模块01）。
重要跟进分层
按 A/B/C 设计 3 套跟进，C 类长线客户推多城联动（上海/北京/西安），别只推单城。
重要季节/安全前置
张家界国庆人海、夏季高温、天门山冬季结冰缆车停运，主动管理预期。
重要成交 CTA
高意向段只到「发方案」，缺付 30% 定金锁档期+建群+行前提醒，与 SOP 脱节。
重要支付说明
明确收款方式（卡/PayPal/Wise）、国际机票不含、定金比例。标★口径先问主管。
加分英文母语润色
opening/objection 段有中式表达瑕疵，找母语者润色过一遍更专业。
加分饮食/宗教预案
清真/素食/过敏未问，是体验翻车高发区。进线即问忌口，预锁餐厅（模块02记）。

📘 长线实战对照（30天多城）· 同行对话拆解与我们的打法
把一份同行（Fancydeeptour 定制师）接 30 天 / 10 城长线 的对话，拆成「对方漏点 = 我们抢点」：

① 破冰首响 → 用 /first-long：信任钩子（不进店 / 英文向导 / 24-7）+ 把预算、签证国籍、兴趣动机前置问齐。对方先聊城市再补问题，我们是先锁资格再出方案。

② 客户说"从香港来" → 用 /visa-hk：对方只回"近、方便"，我们立刻提示香港与内地签证分开，30 天内地游大概率要 L 签（我们出邀请函），并追问护照国籍——立"专业、替我想到了"的信任。

③ 路线提案 → 用 /long-route：直接抄对方"无折返路线"亮点（上海→北京→西安→成都→重庆→张家界→昆明→广州），点明越往后越轻松；紧接 /long-pace 补对方漏问的"快刷多城 vs 慢深度"，定基调再出行程。

④ 报价 → 用 /long-quote（★先问主管）：把大交通拆分（上海→昆明机票、昆明→广州高铁代订）写进包含项，含 / 不含清晰。

⑤ 逼单 + 成交 → 用 /long-push（★）软逼 30% 定金（30 天跨 8 城档期紧 + 早鸟锁价）；用 /long-deal（★）给分期定金 30/30/40 降大单门槛。对方全程"soon 再说"，我们用明确下一步拿下。

一句话：对方强在路线设计，弱在资格筛查 + 信任背书 + 流程节奏——这三块正是我们 /first、/obj-visa、/obj-safe 的看家武器。
📗 外国人眼中的中国 · 谈资与异议预演
他们被什么吸引（hooks — 破冰 / 点燃兴趣用）
• 自然奇观：张家界阿凡达山、桂林山水、九寨、西藏
• 文化符号：大熊猫、长城、故宫、兵马俑
• 美食诱惑：火锅、小笼、潮汕牛肉火锅、街头小吃
• 现代反差：上海天际线、高铁、深圳——"和想象中不一样"
• 历史厚度：千年古都、丝路、少数民族风情

他们常有的顾虑（提前异议处理 — 对应我们的话术）
• 安全？→ /obj-safe（不进店 / 英文向导 / 24-7 / 退款保障）
• 语言不通？→ 全程英文向导 + 微信翻译，我们兜底
• 网络用不了（Google / WhatsApp）？→ 落地前发"中国上网指南"，教装微信
• 支付麻烦（没支付宝）？→ 行程款我们代收代付，客户不操心零散支付
• 吃得惯吗（辣 / 怪）？→ 可定制清真 / 素食 / 不辣，潮汕粤菜清淡友好
• 怕购物团？→ 100% 无购物写进合同
• 签证麻烦？→ /obj-visa、/visa-hk 主动帮办

怎么用（SalesCoach 视角）
• 破冰先问一句："你脑海里 China 第一个画面是什么？"——瞬间打开话匣子，也暴露他的兴趣点与盲区。
• 把"想象"当卖点放大器、"顾虑"当提前异议的靶子，两样都接住。
• 别急着纠正，先认同再给选项（/obj-think 思路）。
