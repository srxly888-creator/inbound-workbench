# 素材库使用说明

> WhatsApp 沟通的高转化动作之一，就是**适时发一张图 / 一段好评截图**。素材必须分门别类、随手可取。

## 目录结构

```
07_素材/
├─ 景点图/         按目的地分子文件夹（如 北京/、成都/、贵州/）
├─ 视频/           短视频（15-60 秒），客户最爱看
├─ 客户好评/       按目的地 / 主题分（截图请打码个人信息）
├─ 行程示意图/     自制的高铁线路 / 城市动线图
└─ 知识小卡/       签证 / 文化 / 美食小图（提升专业感）
```

> 当前 `07_素材/` 仅有本 README，子文件夹在你有素材时按需创建即可。

## 命名规则
- 景点图：`目的地-景点-场景.jpg`（如 `北京-故宫-雪景.jpg`）
- 视频：`目的地-主题-时长.mp4`（如 `成都-熊猫-30s.mp4`）
- 客户好评：`国家-客户代号-主题.png`（如 `美国-CZ001-北京家庭.png`）

## 使用规则
- ✅ **可以发**：自己拍的、客户授权的、官网公开宣传图、官方旅游局授权
- ❌ **不发**：未授权客户图片、网图未标注来源、负面 / 争议图
- 客户好评截图**必须打码**个人信息（电话、姓名、订单号）
- 视频发出去前自己先看一遍（声音 / 内容是否合适）

## 发送时机（销售教练建议）
- 报价后：发 1 张目的地主图 + 1 条客户好评截图
- 客户犹豫：发 1 段目的地短视频（30 秒内）
- 客户问安全：发 1 张好评截图（"这个客户第一次来中国"的话术）
- 客户问定制：发 1 张行程示意图 + 1 张景点图

## 每周整理
- 周一花 15 分钟：补齐上周缺的主题
- 每月底通读一遍"客户好评"，挑出 3 条最有力的置顶

---

## 销售教练三问
- 你手上有几张能"一句话勾起客户兴趣"的图？
- 你的客户好评截图是按目的地分，还是堆在一个文件夹？
- 客户问"安全吗"的时候，你能 5 秒内调出一张相关好评吗？

> **好的素材让客户自己说服自己**。你话术再强，不如一张触动他的图。
