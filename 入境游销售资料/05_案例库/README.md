# 案例库使用说明

> 每个销售最终都会变成"案例的集合"。成交的要知道为什么成，流失的要知道为什么走。

## 命名规则
`YYYYMMDD_客户代号_状态_主题.md`
例如：`20260817_CZ-2026-001_成交_北京5日家庭.md`

## 子目录
- `成交案例/` — 完整成交流程，可复用话术
- `流失案例/` — 流失原因复盘，可避坑

> ⚠️ 还没有成交案例目录的子文件夹，先用 README 占位。沉淀时按状态分目录放即可。

## 每个案例必填字段

```markdown
# 案例：[客户代号] - [成交/流失] - [日期]

## 客户画像
- 国家 / 语言 / 年龄 / 职业
- 出行时间 / 人数 / 天数
- 预算范围

## 需求要点
- 第一次来中国？/ 家庭/夫妻/朋友？/ 兴趣偏好？
- 是否有特殊需求（无障碍 / 素食 / 老人小孩）

## 沟通过程（关键时刻）
- Day 1: 客户第一句话问什么？我怎么答的？
- Day 3: 报价前后客户犹豫什么？
- Day 7: 什么动作让客户决定？
- 流失案例：流失前最后一句对话是什么？

## 成交 / 流失原因
- （用 1–3 个 bullet 写清"为什么"）

## 学到的（沉淀）
- （这条案例可复用的点是什么？下次怎么用？）

## 给同事的提醒
- （如果你明天有同事接手类似客户，第一句要告诉他什么？）
```

## 沉淀节奏
- 每成交 1 单 → **24 小时内**写一个成交案例
- 每流失 1 单 → **当周**复盘写一个流失案例
- 每月底通读本月 5 个案例，提炼共性 → 写入 `00_公司介绍与卖点.md` 或本目录 `月度复盘.md`

## 不写进案例库的
- 客户真实姓名 / 护照号 / 联系方式（用代号即可）
- 内部定价细节（用区间描述）

---

## 销售教练三问（每月末回答）
- 本月最让你骄傲的一单，靠的是哪一句话？
- 本月最让你心疼的一单，输在了哪一步？
- 如果让你给下一个新销售讲这周的故事，你会先讲哪一单？

> 一个写清楚的案例，胜过十次模糊的"感觉"。
