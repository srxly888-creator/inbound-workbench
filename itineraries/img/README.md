# 线路封面图目录 · itineraries/img/

用 ChatGPT（或任意工具）生成的**每条线路封面图**放在本目录，工作台「国内线路」模块会自动显示。

## 命名规则（必须与代码里的 img 字段完全一致）
文件名 = `市场-线路名.jpg`

例如（取自产品矩阵摘要）：
- `贵州-黄小西漫游记4日.jpg`
- `北京-精品定制5日.jpg`
- `张家界·湖南-顶奢张家界5天.jpg`
- `上海·华东-旧梦苏杭4日.jpg`

> 市场名里的 `·` 也要保留（如 `张家界·湖南`、`上海·华东`、`河北·内蒙`）。

## 操作
1. 用 ChatGPT 生成一张有代表性的目的地封面图（横图 16:10 最佳）。
2. 按上面规则命名，放进这个 `img/` 文件夹。
3. 重新 push 到 GitHub Pages（或本地提交后 push），刷新工作台即可看到。

## 说明
- 放进来之前，卡片显示灰色「待补封面图」占位，不影响文字和报价。
- 文件名含中文没问题；若某些系统上传报错，可临时改成拼音名并同步改 `入境游工作台.html` 里 ROUTES 的 `img` 字段。
- 图片为公开营销用途，请使用你有权使用的素材。
